## 3. 웹 채팅 변경 (PR #10, #12)

서버 첫 화면(`/`)의 웹 채팅(`ask-campus/src/server/templates/chat.html`)을 시안대로 바꿨습니다. 쓰는 API(`/api/v1/ask`, `/api/v1/feedback`)는 그대로입니다.

| 화면 | 구현 |
|---|---|
| 00 시작 | 마스코트와 앱 이름 (약 1초) |
| 01 캠퍼스 선택 | 처음 들어올 때만 보임. 고른 캠퍼스는 브라우저에만 저장 |
| 02 첫 화면 | 추천 질문 칩 5개, 안내 상자 |
| 03 찾는 중 | "학교 홈페이지에서 찾는 중이에요" |
| 04 답변과 출처 | 첫 줄 굵게, 목록, 출처 카드(종류·제목·메뉴 위치·수집일·원문 보기), '답이 이상해요' |
| 05·06 되묻기 | 선택지 칩, 고른 칩 표시 |
| 07 찾지 못했을 때 | 서버가 담당 부서를 알려 주면 담당 부서 카드 |
| 08·09 의견 | 아래에서 올라오는 시트(300자), 보낸 뒤 안내 |

**시안과 다르게 만든 부분**

| 화면 | 시안 | 웹 채팅 | 이유 |
|---|---|---|---|
| 07 | "같은 질문이 쌓이면 학과 조교가 답을 달아 FAQ에 올려요" | 넣지 않음 | 조교 전달 흐름은 11/21에 없앰 |
| 07 | 생활관 행정실, 041-000-0000 | 서버 답의 실제 값 | 시안 값은 예시 |
| 05 | 졸업 요건 질문에 학과를 물음, 선택지 4개 | 공모전 목록 질문에만 학과를 물음, 학과 전체 | 서버 동작이 그러함 |
| 02 | 추천 질문 칩 | 칩을 화면에 고정 | 추천 질문 API 없음 (FR-006 미착수) |
| 02·06 | '다음 천안역 버스', 온양온천역·배방역 등 | '두정역 다음 통학버스 언제야?', 서버가 주는 실제 정류장 | 천안역·온양온천역 등은 통학버스 정류장이 아님 (PR #12) |
| 00·10 | 학교 로고 | 넣지 않음 | 홈페이지에서 캡처한 임시 이미지, 사용 허가 전 |
| 10 앱 정보 | 화면 있음 | 만들지 않음 | 시안에 이 화면으로 가는 버튼이 없음 |

**확인한 것**
- 실제 서버 답을 넣어 화면 9장을 캡처해 봤습니다. 출처 카드에 메뉴 경로 대신 주소 조각(`/u1/.../change.do`)이 나와 칸을 넘는 문제를 찾아 고쳤습니다.
- '두정역 다음 통학버스 언제야?'는 서버가 통학버스 시간표로 답했습니다 (문서, 0.2초, 11/25).

## 4. 전시회 판넬 (PR #10, #12, #13)

| 항목 | 내용 |
|---|---|
| 틀 | 학교 샘플 판넬(05_캡스톤디자인_전시회_판넬)의 배경·5칸·제목 띠·글자 서식 |
| 내용 | 1 개요, 2 개발 환경 및 주요 기능, 3 개발 내용 및 과정(구성도, 답변 과정 ①~⑦, 모델 선정, 개인정보 보호), 4 개발 결과(웹 채팅 화면 4장), 5 결론(평가 결과, 결론, 남은 과제) |
| 수치 | 11주차 진행보고서의 값 (11/22~23 측정) |
| 생성 | `문서/작업/전시회판넬/build_panel.py` (샘플 파일은 리포에 넣지 않음) |
| 파일 | `물어봐캠퍼스_전시회_판넬_1조.pptx` (팀 사진 포함). 공개 리포라 사진이 든 파일은 올리지 않음 |

- 개발 결과 칸 그림은 처음에 Figma 시안을 넣었다가, 시안의 정류장·시간이 실제와 달라 실제 서버 답으로 찍은 웹 채팅 화면으로 바꿨습니다 (PR #12).
- 구성도는 요구사항 정의서의 예전 그림(온통청년 API, 조교 흐름)이 지금과 달라 새로 그렸습니다.

## 6. 남은 문제

| 문제 | 내용 |
|---|---|
| Android 앱 | 시안을 아직 반영하지 않음. 되묻기 선택지와 '답이 이상해요'도 앱에는 없음 |
| 10 앱 정보, 추천 질문 API | 미구현 (FR-006, SCR-004) |
| 학교 로고 | 판넬 시작 화면에는 없음(구현 화면 사용). Figma 시안에는 임시 로고가 있어 원본과 사용 허가 필요 |
| Figma 07 화면 문구 | 조교 안내 문구가 남아 있어 지금 동작과 다름 |
| 천안아산역 | 학교 자료의 3호차 운행노선표에 천안아산KTX역이 있어 정류장 선택지에 나옴. 실제 운행 여부 확인 필요 |
| 시작 화면 부제목 | 후보 "공지 뒤지지 말고, 그냥 물어봐", 확정 여부 확인 필요 |
| 11주차 보고서의 남은 문제 | 처음 보는 질문 정확도, 자료에 없는 질문 거르기, 첨부파일 본문, 자동 재수집 기록 등은 그대로 |
