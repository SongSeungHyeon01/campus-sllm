# Figma MCP 호출이 Starter 플랜 한도에 걸려 화면 수정이 멈춤

- **발생 시각**: 2026-11-25
- **위치**: Figma MCP `use_figma` (파일 `물어봐 캠퍼스 UI`, 00 시작 화면 문구 수정)
- **상태**: 우회함 (문구는 Figma에서 직접 고침)

## 증상
00 시작 화면의 부제목을 바꾸는 `use_figma` 호출이 다음 메시지로 실패했다.

> You've reached the Figma MCP tool call limit on the Starter plan.

같은 세션에서 앞서 한 작업은 모두 성공했다. 파일 생성, 화면 11장 작성, 색 변경, 캐릭터 생성, 로고 업로드에 MCP를 수십 번 호출했다.

## 원인 조사
- 코드 오류는 아니다. 같은 형태의 스크립트(텍스트 교체)가 바로 전까지 성공했다.
- `whoami` 기준 파일을 만든 팀 플랜이 `starter` 등급이다.

## 근본 원인
Figma MCP는 플랜마다 호출 횟수에 한도가 있고, Starter 플랜 한도를 다 썼다. 한도가 다시 채워지는 주기는 Figma 문서(https://developers.figma.com/docs/figma-mcp-server/rate-limits-access/)를 따르며, 이번 세션에서는 확인하지 않았다.

## 해결 방법 / 다음 시도
- 남은 수정(부제목 문구)은 Figma 앱에서 직접 고친다.
- 한도가 풀린 뒤 이어서 작업하거나, 상위 플랜(Professional 이상)을 쓰는 계정에서 작업한다.

## 재발
- 2026-11-25 같은 날 다시 시도했다. 부제목 텍스트 하나만 바꾸는 `use_figma` 1회 호출이 같은 메시지로 실패해, 한도가 아직 풀리지 않은 것을 확인했다.

## 재발 방지
- MCP 호출을 아낀다. 스크린샷은 화면을 다 만든 뒤 한 번만 찍고, 작은 수정은 여러 개를 모아 한 번에 호출한다.
- 화면이 많이 남은 작업은 시작하기 전에 남은 한도를 고려한다.
