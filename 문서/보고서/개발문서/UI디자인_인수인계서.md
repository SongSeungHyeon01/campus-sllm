## 4. 화면 11장과 구현 상태

구현 상태는 2026-11-25에 `ask-campus/src/server/`와 `android/` 코드를 보고 적었습니다. 앱은 채팅 화면 하나(`MainActivity.kt`)뿐입니다.

| 번호 | 화면 | 서버 | Android 앱 |
|---|---|---|---|
| 00 | 시작 화면 (마스코트, "물어봐 캠퍼스", 학교 로고) | 해당 없음 | 없음 |
| 01 | 캠퍼스 선택 (첫 실행) | `campus` 값("영동"/"아산"/null)을 받음 | 첫 실행 선택 없음. 기본값은 아산. 메뉴 '캠퍼스 바꾸기' 대화상자는 있음 |
| 02 | 첫 화면 (추천 질문 칩) | 추천 질문 API 없음 (FR-006 미구현) | 칩 없음. 첫 말풍선에 예시 질문 문장만 있음 (`strings.xml`의 `welcome`) |
| 03 | 답을 찾는 중 | 해당 없음 | 있음. "답변을 찾고 있어요…" 말풍선 |
| 04 | 답변과 출처 | 구현됨 (`sources[]`: 제목·종류·원문 주소·메뉴 경로·수집일) | 구현됨 (출처·수집일, 위치, '원문 보기 ↗') |
| 05 | 되묻기 - 학과 | 구현됨. **공모전 목록 질문에 학과가 없을 때만** 물음. `clarify.field = "department"`, 선택지는 그 캠퍼스 학과 + '전체 보기' + 전체, `more`에 두 캠퍼스 학과 전체 | 없음. `AskApi.kt`가 `clarify`를 읽지 않아 질문 문장만 보임 |
| 06 | 되묻기 - 정류장 | 구현됨. 통학버스 시간을 묻는데 정류장이 없으면 물음. `clarify.field = "refine"`, 선택지는 그 캠퍼스 시간표의 정류장 이름 | 없음 (05와 같은 이유) |
| 07 | 찾지 못했을 때 | 구현됨. "해당 정보를 찾을 수 없습니다. 학교 홈페이지나 담당 부서에 문의해 주세요." + 담당 부서를 알면 안내 한 줄. 답변 대기에 자동 등록 (`pending_registered`) | 답 문장은 그대로 보임. '조교에게 전달됨' 안내는 11/21부터 숨김 |
| 08 | 의견 시트 | 구현됨. `POST /api/v1/feedback`, `comment` 300자까지, 답 하나에 한 번 | 없음. `log_id`를 읽지 않음 (웹 채팅에만 있음) |
| 09 | 보낸 뒤 | 저장 후 응답만 줌 | 없음 |
| 10 | 앱 정보 (캠퍼스, 답을 찾는 곳, 오픈소스 라이선스, "학교 공식 앱이 아니에요") | 해당 없음 | 없음. 메뉴는 '캠퍼스 바꾸기', '서버 주소' 두 개뿐 (SCR-004 미구현) |

- 웹 채팅(`ask-campus/src/server/templates/chat.html`)에는 05·06 선택지 버튼과 08 피드백이 이미 있습니다. 앱에 옮길 때 동작을 참고하면 됩니다.
- API 요청·응답 형식은 `프론트_인수인계서.md` 7절에 있습니다.

## 5. 주의할 점

| 항목 | 내용 |
|---|---|
| 예시 값 | 화면 속 버스 시간, 전화번호 041-000-0000, "생활관 행정실", 수집일 11월 20일, 버전 0.1은 **예시 값**입니다. 실제 값은 서버 응답으로 채웁니다 |
| 시작 화면 부제목 | "학교 일은 물어보면 찾아 드려요"는 바꾸기로 함. 후보는 "공지 뒤지지 말고, 그냥 물어봐" (최종 확정 여부 확인 필요) |
| 학교 로고 | 홈페이지에서 캡처한 **임시 이미지**입니다. 앱에 넣기 전에 원본 파일과 학교의 사용 허가가 필요합니다 |
| 마스코트 | Figma AI로 만든 이미지(1024px). 앱용 내보내기 크기는 정하지 않았습니다 |
| Figma MCP | Starter 플랜 호출 한도에 걸려 있습니다 (`문서/보고서/개발문서/오류보고서/2026-11-25_figma-mcp-starter-call-limit.md`). Figma 수정은 Figma 앱에서 직접 하거나 한도가 풀린 뒤에 합니다 |
