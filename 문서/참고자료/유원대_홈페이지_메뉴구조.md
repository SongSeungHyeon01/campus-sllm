# 유원대학교 홈페이지 메뉴 구조 조사

- 조사일: 2026-10-09
- 조사 대상: https://www.u1.ac.kr (사이트맵 전체 235개 메뉴)
- 목적: 요구사항 정의서의 메뉴 경로(FR-022, menu_path)와 수집 대상(FR-014) 확인

## 1. 핵심 결과

### 1.1 아산캠퍼스 전용 사이트는 없음
영동·아산이 **같은 홈페이지**를 쓰고, 메뉴 안에서 캠퍼스별로 나뉩니다. 아산캠퍼스가 따로 나뉜 메뉴는 다음과 같습니다.

| 메뉴 | 아산캠퍼스 페이지 |
|---|---|
| 대학소개 > 캠퍼스안내 > 오시는길 | 아산캠퍼스 (/u1/introduction/location02.do) |
| 대학소개 > 캠퍼스안내 > 캠퍼스맵 | 아산캠퍼스 (/u1/introduction/campus-map02.do) |
| 대학·대학원 > 아산캠퍼스 | 학과 16개 (AI소프트웨어학과 /computer/index.do 포함) |
| 대학행정 > 조직도 | 아산캠퍼스 조직도 (/u1/administration/organ02.do) |
| 대학생활 > 통학버스 > 아산캠퍼스 | 통학버스 (bus02.do), **주말·공휴일·방학 (bus02-01.do)** |
| 대학생활 > 학교 구내식당 | 한 페이지에 [영동 중식], [아산 중식], [아산 석식]이 함께 표시 |

동아리현황, 학사일정, 공지사항은 캠퍼스 구분 없이 한 페이지입니다.

### 1.2 최상위 메뉴 7개
대학소개 · 입학안내 · 대학·대학원 · 대학행정 · 학사안내 · 대학생활 · 커뮤니티

### 1.3 요구사항 정의서와 다른 메뉴 경로

| 문서 위치 | 문서에 적힌 경로 | 실제 경로 |
|---|---|---|
| 시나리오 7, FR-022 예시 | 홈페이지 > 대학생활 > 동아리현황 | **홈 > 대학생활 > 학생기구 > 동아리 > 동아리현황** |
| FR-004·FR-022 예시, SCR-001 그림 | 홈페이지 > 커뮤니티 > 학사공지 | **홈 > 커뮤니티 > 공지사항 > 학사공지** |

두 곳 모두 중간 단계 메뉴가 빠져 있습니다. 실제 사이트 표기는 "홈페이지"가 아니라 "홈"으로 시작합니다.

### 1.4 새로 찾은 쓸 만한 데이터

| 메뉴 | 내용 | 활용 |
|---|---|---|
| 대학생활 > **학교 구내식당** (/u1/life/cafeteria.do) | 주간 식단 (영동 중식, 아산 중식·석식) | "오늘 아산 학식 뭐야?" 같은 질문. 학생 수요가 높을 가능성이 큼 |
| 커뮤니티 > **Q&A** (/u1/community/qna.do) | 로그인 없이 볼 수 있는 학생 질문 게시판, 약 1,120건 (예: "교양 재수강", "졸업관련") | 실제 학생 질문이라 **테스트 질문셋(FR-018)과 FAQ 후보**로 활용 가치가 큼 |
| 대학생활 > 통학버스 > 아산캠퍼스 > **주말,공휴일,방학** (bus02-01.do) | 아산 주말·방학 운행표 | FR-010에 아산 주말·방학 시간표가 빠져 있어 추가 필요 |
| 커뮤니티 > 공지사항 > **장학공지·취업공지** | 장학금, 채용·자격증 지원 공지 | 교외활동(FR-013)·학사정보 보강 |
| 학사안내 > 수업정보·성적정보·학적정보·장학정보 | 수강신청안내, 계절학기, 시험, 졸업, 등록안내, 교내장학 등 고정 안내 페이지 | 학사요람 외 학사정보 근거 문서 |
| 커뮤니티 > U1소식 > **학과소식** | 학과별 소식 | 학과 공지 보강 |
| 대학행정 > 조직도 > 아산캠퍼스 조직도 | 부서 안내 | "장학금 문의 어디로 해요?" 같은 질문 |

### 1.5 수집할 수 없거나 주의할 메뉴
- 커뮤니티 > **FAQ**: 로그인 필요 (기존 확인 내용과 같음)
- 학사안내 > 수업정보 > **강의계획서**: 외부 시스템(spview.u1.ac.kr) 새 창
- 입학안내 전체, 대학원, 일부 관련기구: 별도 사이트(ipsi.u1.ac.kr, graduate.u1.ac.kr)로 이동
- 각 학과 홈페이지: 학과마다 별도 사이트 구조라 학과 공지는 AI소프트웨어학과부터 따로 확인 필요
