## 2. 핵심 결론

### 2.1 해커톤 분석에서 얻은 것 (자세한 내용은 `해커톤_발표분석.md`)

- **진행 방식:** 팀당 약 10분(발표 5~7분 + 질의응답 3~4분). 시연은 녹화 영상이 표준. 질의응답은 시간이 되면 중간에 끊김.
- **점수를 얻은 패턴:**
  - 문제를 한 문장으로 다시 정의함 (예: "총무의 노동")
  - 직접 잰 수치를 제시함 (예: 167개 중 165개 인식)
  - AI 결과를 단계별로 검증하고 마지막은 사람이 확인하는 구조를 보여 줌
  - 한계를 먼저 밝힘
- **점수를 잃은 패턴:**
  - "ChatGPT로 되잖아?"에 약하게 답함
  - 데이터 출처·신뢰성이 미정
  - 개인정보 질문에 "문제없을 것 같다"고 답함
  - 시장 규모를 수익 모델과 연결하지 못함
- **가장 날카로운 심사위원의 기준:**
  - "땀 냄새 나는 검증"
  - "AI 모델이 아니라 우리가 무엇을 했기에 다른가"

### 2.2 물어봐 캠퍼스에 적용 (자세한 내용은 `발표적용_인수인계서.md`)

- **이미 강점인 부분:** 검증 파이프라인을 이미 갖추고 있어요. 순서는 아래와 같아요.
  1. 검색 기준값 0.60
  2. 버스 시간은 코드가 계산
  3. 근거 없음 판정
  4. 출처 표시
  5. 조교 답변이 FAQ로 반영
  
  → 발표에서 다이어그램 1장으로 보여 주면 돼요.
- **"땀 냄새" 근거로 쓸 소재:**
  - 버스 오답 사례: 08:00이 맞는데 10:15로 답했어요.
  - 11/10 근거 없음 문구 누락 사례: `docs/오류보고서/2026-11-10_not-found-phrase-and-answer-cleanup.md`
- **가장 큰 빈칸:** 정확도 수치였어요. 3절의 평가 질문셋으로 첫 측정을 했어요.
- **제외한 부분:** 사업 모델·시장 규모는 캡스톤에 해당하지 않아 뺐어요. 대신 운영 지속성 질문(조교 부담, 서버, 갱신)을 대비 항목에 넣었어요.

## 3. 평가 질문셋과 첫 측정 결과

### 3.1 질문셋 (`ask-campus/eval/questions.jsonl`)

| 종류 | 개수 | 구성 |
|---|---|---|
| answer (자료에 답 있음) | 80 | 학사일정 20, 학사공지 20, 일반공지 15, 동아리 5, 장학 12, 통학버스 8. 정식 55개, 구어체 25개 |
| none (자료에 없음) | 20 | 기숙사 신청 기간, 학식, 도서관 시간, 편입 학점, 졸업 학점, 와이파이 등 |
| trap (자료에 일부만 있음) | 8 | 시험 장소, 한맥 연락처(`010-`), 회비, 첨부파일에만 있는 정보, 생활관 신청 기간 등. 지어내지 않는지 사람이 확인 |

- 필드 설명
  - `gold`: 정답 근거 청크에 들어 있는 문자열이에요. 검색 결과 본문에 하나라도 있으면 정답 근거로 봐요.
  - `expect`: 답변에 들어가야 할 문자열이에요. sLLM 전체 평가용이고, 아직 쓰지 않았어요.
- 모든 `gold` 문자열은 `data/chunks.jsonl`에 실제로 있는지 확인했어요. 평가 스크립트도 실행할 때마다 다시 확인해요.

### 3.2 평가 스크립트 (`ask-campus/scripts/eval_retrieval.py`)

- sLLM 없이 임베딩·벡터 검색만 평가해요. 실행 시간은 1분 이내예요.
- 실행 방법 (`ask-campus` 폴더에서):
  ```
  .venv\Scripts\python scripts\eval_retrieval.py
  ```
- 출력 내용
  - 상위 1·3·5 정답률
  - 분야별·말투별 정답률
  - 근거 기준값별 비교표
  - 상위 3에 못 든 질문 목록
- 결과는 `eval/results/retrieval_날짜_시각.json`에 저장돼요.

### 3.4 결과를 해석할 때 주의할 점 (발표 전에 꼭 확인)

- **98.8%는 낙관적인 수치예요.** 질문을 만든 사람이 수집 자료를 보고 썼기 때문에 질문 표현이 자료와 비슷해요. 발표에서는 "개발자가 작성한 질문셋 기준"이라고 밝혀야 해요.
- 중간보고서에서 실패했던 실제 구어체 질문("학교 동아리 뭐있냐 지금 신청할만한거 아산")은 이 질문셋에 그대로 들어 있지 않아요.
- 실제 학생 질문으로 다시 재야 해요. 재료는 아래와 같아요.
  - 2차 설문 Q7
  - 홈페이지 Q&A 게시판 (약 1,120건)
- 상위 3 정답률은 높지만, 실제 답변 단계에서는 **기준값 0.60 때문에 답 있는 질문 8개가 근거 없음으로 처리**되고 **자료에 없는 질문 3개가 통과**해요. 실제 사용자가 체감하는 정확도는 상위 3 정답률보다 이 수치에 더 가까워요.
- 이 측정은 검색 단계만 본 것이에요. sLLM이 만든 답변이 맞는지는 아직 재지 않았어요.
