## 2. MVP 프로토타입 (10/12)

| 구성 | 기술 |
|---|---|
| 답변 sLLM | `kakaocorp/kanana-1.5-2.1b-instruct-2505` (bf16, 파인튜닝 전) |
| 검색 임베딩 | `nlpai-lab/KURE-v1` (fp16) |
| 저장소 | Chroma (자료 청크 154개), SQLite (청크·답변 대기·FAQ·질문 기록) |
| 서버 / 조교 웹 | FastAPI / Jinja2 (임시 비밀번호 로그인) |
| 앱 | Android (Kotlin, Android 8.0 이상) |
| 수집 자료 | 공지(학사·일반·장학), 학사일정 66건, 통학버스(영동·아산, 주말·방학), 동아리현황. 10/12 수집 |

**답변 흐름**
1. 질문이 FAQ와 비슷하면(0.75 이상) 조교 답변으로 바로 답합니다.
2. 아니면 자료를 검색합니다. 근거 점수가 0.60보다 낮으면 근거 없음으로 봅니다.
3. 통학버스 시간 질문은 서버 코드가 시간표를 계산해서 답합니다.
4. 그 밖의 질문은 sLLM이 근거 자료로만 답합니다.
5. 근거가 없으면 질문을 답변 대기에 자동 등록합니다. 비슷한 질문은 하나로 묶습니다.

**개발 중 만난 문제** (`docs/오류보고서/`, 모두 해결 또는 우회)

| 문제 | 해결 |
|---|---|
| transformers 5.x가 Kanana 설정을 거부 | 4.57.6으로 고정 |
| GPU 메모리 부족으로 답변에 18~48초 | 임베딩을 fp16으로, 에뮬레이터의 GPU 사용을 끔 |
| 학사일정 검색이 빗나감 | 일정 하나를 청크 하나로 분리 |
| 자료에 없는 내용을 지어냄 | 근거 기준값 0.45 → 0.60 |
| FAQ 등록 직후 500 오류 (Chroma) | FAQ·답변 대기 벡터를 SQLite로 이동 |
| "가장 빠른 버스"에 08:00 대신 10:15로 답함 | 시간표 조회는 코드가 계산, 현재 시각을 모델에 전달 |
| Android 빌드 실패 (Java 25, SDK 경로) | JDK 21 사용, `local.properties`는 슬래시로 |

## 4. 평가와 모델 선정 (11/10)

### 평가 질문셋과 검색 정확도
- 평가 질문 108개를 만들었습니다: 자료에 답 있는 질문 80개(구어체 25개 포함), 자료에 없는 질문 20개, 자료에 일부만 있는 질문 8개.
  - 파일: `ask-campus/eval/questions.jsonl`
- 검색 정확도(정답 근거가 상위 3개 안에 든 비율)는 **79/80 (98.8%)** 였습니다. 목표는 80%입니다.
- 근거 기준값 0.60에서는 답 있는 질문 72/80을 살리고, 자료에 없는 질문 17/20을 걸러 냈습니다.
- **한계:** 질문을 개발자가 자료를 보며 써서 낙관적인 수치입니다. 실제 학생 질문으로 다시 재야 합니다.
- 실행: `ask-campus/scripts/eval_retrieval.py`

### sLLM 비교
- Hugging Face에서 후보를 골랐습니다. 조건은 세 가지였습니다: 노트북 GPU 8GB, 한국어 지원, 라이선스.
- 같은 질문 19개를 같은 조건으로 시험했습니다(원본 bf16, 임베딩 CPU, 시각 고정).

| 모델 | 답 있는 질문 (12) | 자료에 없는 질문 (4) | 평균 생성 시간 |
|---|---|---|---|
| **Kanana 1.5 2.1B (유지)** | **12** | 4 | 2.1초 |
| Midm 2.0 Mini | 11 | 4 | 2.4초 |
| Kanana-2 3B | 8 | 4 | 1.65초 |

- Kanana-2 3B는 압축하면 더 나빴습니다: 8bit에서 10/12, 4bit에서 5/12. 4bit에서는 날짜를 지어냈습니다.
- 요구사항 정의서의 비교 모델 Qwen3.5 2B는 transformers 5.x가 필요해서, 별도 환경을 준비하다 중단했습니다(미시험).
- **결론:** Kanana 1.5 2.1B를 유지합니다.
- 실행: `ask-campus/scripts/model_compare.py`

### 비교 중 찾아 고친 문제
- **근거 없음 판정 누락:** 다른 모델이 "제공되지 않았습니다"라고 답하면 근거 없음으로 판정되지 않았습니다. 판정 문구를 추가했습니다.
- **답변 찌꺼기:** 답변에 빈 칸 "연락처: 010-", 맺음말, HTML 태그가 섞였습니다. 후처리에서 지웁니다.
- 기록: `docs/오류보고서/2026-11-10_not-found-phrase-and-answer-cleanup.md`
- **추가한 옵션:**
  - `ASK_LLM_QUANT` (4bit·8bit)
  - `ASK_EMBED_DEVICE` (임베딩 cpu)
  - Qwen 계열의 생각 모드 끄기
