## 2. 코드 받기와 git 설정

```powershell
cd C:\dev
git clone https://github.com/SongSeungHyeon01/campus-sllm.git "Campus sLLM"
cd "C:\dev\Campus sLLM"
git config core.hooksPath .githooks
git config user.email "<GitHub ID>+<사용자명>@users.noreply.github.com"
```

- `core.hooksPath`를 설정하면 커밋·푸시 직전에 개인정보 검사기(`.githooks/`)가 자동으로 돕니다.
- `user.email`에는 GitHub noreply 주소를 씁니다. 주소는 GitHub 웹 설정 → Emails에 나옵니다.
  - 리포가 **공개**라서, 개인 이메일로 커밋하면 그 주소가 그대로 공개됩니다.
  - 같은 화면에서 "Keep my email addresses private"와 "Block command line pushes that expose my email"도 켭니다.

## 3. 서버 (ask-campus)

```powershell
cd "C:\dev\Campus sLLM\ask-campus"
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cu128
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -c "import torch;print(torch.__version__, torch.cuda.is_available())"
```

- 마지막 줄 결과가 `2.11.0+cu128 True`면 됩니다.
- **torch는 반드시 cu128 주소로 먼저 설치합니다.** 그냥 `pip install torch`로 설치하면 GPU를 못 씁니다.
- **transformers는 4.57.6 고정입니다.** 5.x로 올리면 Kanana 모델이 열리지 않습니다.
- 모델 비교에서 4bit·8bit를 시험하려면 `bitsandbytes`를 추가로 설치합니다 (선택).

**사용 모델** (처음 실행할 때 Hugging Face에서 자동으로 받고, 합쳐서 약 5GB)

| 용도 | 모델 |
|---|---|
| 답변 (sLLM) | `kakaocorp/kanana-1.5-2.1b-instruct-2505` (bf16, 약 4.2GB) |
| 검색 (임베딩) | `nlpai-lab/KURE-v1` (fp16, 약 1.1GB) |

- 다운로드가 멈추면 `$env:HF_HUB_DISABLE_XET="1"`을 설정한 뒤 다시 실행합니다.
- **NVIDIA GPU가 없거나 8GB보다 작으면** `$env:ASK_USE_LLM="0"`을 설정합니다. 답변 모델 없이 근거 문장만 돌려주는 시험 모드로 동작합니다.

### 데이터 만들기 (처음 한 번)

`ask-campus/data/`는 git에 올리지 않으므로 직접 만듭니다.

```powershell
.venv\Scripts\python -m src.ingest.run --notice-pages 2    # 학교 홈페이지 공개 페이지 수집, 1~2분
.venv\Scripts\python -m src.server.build_index            # DB와 벡터 색인 생성
```

지금 수집하면 공지가 바뀌어 있어서, 시험 결과가 송승현 PC(2026-10-12 수집본)와 다르게 나올 수 있습니다. 결과를 똑같이 맞추려면 `data` 폴더를 따로 받아서 씁니다.

### 실행과 시험

```powershell
$env:ASK_ADMIN_PASSWORD = "<각자 정한 비밀번호>"
$env:ASK_SECRET = "<아무 긴 무작위 문자열>"
.venv\Scripts\python -m uvicorn src.server.app:app --host 0.0.0.0 --port 8000
```

| 스크립트 | 내용 | 서버 |
|---|---|---|
| `scripts\smoke_test.py` | 대표 질문 11개 | 켜고 실행 |
| `scripts\e2e_test.py` | 조교 답변 흐름 9개 (`ASK_ADMIN_PASSWORD` 필요, 시험 데이터가 DB에 남음) | 켜고 실행 |
| `scripts\time_test.py` | 통학버스 시간 10개 | **끄고** 실행 (GPU 메모리) |
| `scripts\eval_retrieval.py` | 평가 질문 108개로 검색 정확도 측정 | 끄고 실행 권장 |
| `scripts\model_compare.py` | sLLM 후보 비교 (DB 복사본 사용) | **끄고** 실행 |

환경변수로 동작을 바꿀 수 있습니다.

| 변수 | 기본값 | 설명 |
|---|---|---|
| `ASK_LLM_MODEL` | `kakaocorp/kanana-1.5-2.1b-instruct-2505` | 답변 모델 |
| `ASK_LLM_QUANT` | (없음, bf16) | `4bit` 또는 `8bit` |
| `ASK_EMBED_DEVICE` | `cuda` | `cpu`면 임베딩을 CPU에서 실행 (큰 모델 시험용) |
| `ASK_USE_LLM` | `1` | `0`이면 답변 모델 없이 근거 문장만 반환 |
| `ASK_MIN_SCORE` | `0.60` | 근거 기준값 |

## 4. Android 앱 (android)

| 항목 | 값 |
|---|---|
| AGP / Gradle / Kotlin | 8.6.0 / 8.7 / 2.2.10 |
| compileSdk · targetSdk / minSdk | 35 / 26 |
| Java 대상 | 17 (빌드는 JDK 21로) |
| 에뮬레이터 | Pixel 2, Android 14 (API 34) Google APIs x86_64 |

1. Android Studio의 SDK Manager에서 다음 두 가지를 설치합니다.
   - **Android 15 (API 35)** 플랫폼
   - **API 34 Google APIs x86_64** 시스템 이미지
2. Gradle JDK를 **JDK 21**로 지정합니다 (Settings → Build Tools → Gradle → Gradle JDK).
   - Android Studio 내장 JDK(Java 25)로는 Gradle 8.7이 실행되지 않습니다.
3. `android\local.properties`를 만듭니다.
   - 이 파일은 git에 올리지 않습니다.
   - 경로는 슬래시(`/`)로 씁니다. 역슬래시를 쓰면 경로가 깨집니다.
   ```
   sdk.dir=C:/Users/<본인 계정>/AppData/Local/Android/Sdk
   ```
4. 빌드합니다: `.\gradlew.bat assembleDebug`
5. 에뮬레이터는 GPU 메모리를 아끼려고 `-gpu swiftshader_indirect` 옵션으로 실행합니다.

## 6. Claude Code 설정

### 리포에 들어 있어 자동으로 적용되는 것 (따로 할 일 없음)

| 항목 | 위치 | 내용 |
|---|---|---|
| 프로젝트 규칙 | `CLAUDE.md` | 개인정보, 커밋 메시지, 문서 수정 방식, 기술 결정과 이유 |
| error-report 스킬 | `.claude/skills/error-report/` | 오류가 나면 `docs/오류보고서/`에 같은 형식으로 기록 |
| git-privacy-guard 스킬 | `.claude/skills/git-privacy-guard/` | 커밋·푸시 전 개인정보·비밀값 검사 |
| 개인정보 검사 훅 | `.githooks/` | 2절의 `git config core.hooksPath .githooks`를 해야 동작 |

**개인 목록 (선택):** 검사기가 자기 본명·개인 이메일·학번도 잡게 하려면 `~/.config/git-privacy/personal.txt`에 한 줄씩 적습니다. 이 파일은 각자 PC에만 두고 리포에 넣지 않습니다.
