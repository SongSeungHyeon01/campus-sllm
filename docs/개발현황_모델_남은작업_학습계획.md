# 물어봐 캠퍼스 개발 현황: 사용 모델, 남은 작업, 학습(파인튜닝) 계획

- 작성일: 2026-10-12
- 기준: MVP 프로토타입 (`ask-campus/`, `android/`), 요구사항 정의서 v1.11, 모델 선정·예산 검토
- 아래 내용은 2026-10-12에 노트북(RTX 5060 Laptop 8GB)에서 실제로 실행·시험한 결과를 기준으로 합니다.

## 1. 지금 쓰는 모델과 구성

| 역할 | 사용 중 | 실행 방식 | 비고 |
|---|---|---|---|
| 답변 생성 (sLLM) | **Kanana 1.5 2.1B Instruct** (카카오, Apache 2.0) `kakaocorp/kanana-1.5-2.1b-instruct-2505` | 노트북 GPU에서 bf16, 약 4.2GB | **파인튜닝 안 함.** 원본 모델 + 프롬프트만 사용. transformers 4.57.6으로 고정 (5.x는 이 모델 설정을 거부함) |
| 임베딩 (검색) | **KURE-v1** (고려대, MIT) `nlpai-lab/KURE-v1` | fp16, 약 1.1GB | 질문과 문서를 숫자 벡터로 바꿔 비슷한 문서를 찾음 |
| 벡터 DB | **Chroma 1.5.9** | 학교 자료 청크 154개 | FAQ·답변 대기는 Chroma 오류 때문에 SQLite에 임베딩을 저장하고 numpy로 유사도 계산 |
| 관계형 DB | **SQLite** | `ask-campus/data/askcampus.db` | chunk, pending_question, faq, query_log (DB 모델링 v1.0의 일부) |
| 시간표 조회 | 모델 없음 (서버 코드) | 계산 | 2B 모델이 '지금 이후 가장 빠른 차'를 고르지 못해 코드가 답함 |

**모델 선정 검토에는 있지만 아직 안 쓴 것**

| 모델 | 용도 | 상태 |
|---|---|---|
| bge-reranker-v2-m3-ko | 검색 결과 재정렬 (상위 3개 정확도, PER-003) | 미사용 |
| Qwen3.5 2B | sLLM 비교 후보 | 미사용 (평가 질문셋이 있어야 비교 가능) |
| BAAI/bge-m3 | 임베딩 비교 후보 | 미사용 |
| EXAONE 4.0 1.2B | 온디바이스 시연 (확장) | 미사용, 1차 범위 밖 |

## 3. 학습(파인튜닝)으로 더 좋아질 수 있나

**결론: 됩니다. 다만 학습으로 고칠 수 있는 문제와 없는 문제가 나뉩니다.**

### 3.1 문제별 판단

| 이번 시험에서 본 문제 | 학습으로 해결? | 이유와 더 나은 방법 |
|---|---|---|
| 자료에 없는 질문에 관련 없는 공지를 엮어 답함 (예: 편입생 학점 인정) | **효과 있음** | "자료에 없으면 '찾을 수 없습니다'라고만 답한다"는 예시로 학습하면 지어내는 답이 줄어듦 |
| 말투·길이 (맺음말을 붙이거나 자료 형식을 따라 씀) | **효과 있음** | 원하는 답 모양으로 학습하면 프롬프트 규칙보다 안정적 |
| 통학버스 '지금 이후 가장 빠른 차' 계산 | **효과 적음** | 2B 모델에게 시간 계산은 학습해도 불안정. 지금처럼 코드로 계산 |
| 버스 시간·학사일정처럼 바뀌는 정보 | **하면 안 됨** | 학습하면 옛 정보를 외워 버림. 요구사항 FR-017도 "자주 바뀌는 정보는 RAG로만" |
| 필요한 문서가 검색에서 밀림 (등록금 환불 2/3선, 시간표 조각) | **모델 학습보다 검색 개선이 효과적** | 리랭커 추가(학습 불필요)가 먼저, 그다음 학교 질문·문서 쌍으로 임베딩 모델 학습 |

### 3.2 권장 순서

1. **평가 질문셋 만들기:** 답이 있는 질문 80개(분야별 20개)에 자료에 없는 질문 20개 정도를 더합니다. 이게 없으면 학습해서 좋아졌는지 알 수 없습니다.
   - 재료: 2차 설문의 실제 질문, 학교 홈페이지 Q&A 게시판(로그인 없이 볼 수 있는 학생 질문 약 1,120건), 조교 FAQ
2. **리랭커 추가와 근거 기준값 재조정:** 학습 없이 검색 정확도를 올립니다.
3. **Kanana 2.1B QLoRA 학습**
   - 데이터: "질문 + 검색된 근거 → 근거만으로 쓴 답" 300~500쌍. '찾을 수 없음' 예시를 일부러 섞습니다.
   - 장소: Colab 무료 T4로 충분합니다(모델 선정 검토의 판단). 노트북 RTX 5060에서도 4bit 학습이 가능할 수 있지만, Blackwell GPU용 bitsandbytes 호환은 아직 확인하지 않았습니다.
4. **같은 질문셋으로 학습 전후 비교:** 좋아졌을 때만 서버에 반영합니다(요구사항 FR-017 비고).
5. **(선택) 임베딩 모델 학습:** 질문과 정답 문서 쌍으로 KURE-v1을 추가 학습해 검색 정확도를 올립니다.

### 3.3 기대치

- **학습으로 좋아지는 것:** 근거에 충실한 답, 모르면 모른다고 하기, 말투와 길이
- **학습으로 바꾸지 않는 것:** 사실 정보는 계속 수집(RAG)이, 날짜·시간 계산은 코드가 맡는 구조를 유지합니다.
