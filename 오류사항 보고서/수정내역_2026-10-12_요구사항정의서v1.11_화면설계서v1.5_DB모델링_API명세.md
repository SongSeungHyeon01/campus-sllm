  - 같은 기기 같은 질문 1회: `notify_token (pending_id, fcm_token)` UNIQUE (FR-028)

  - 중간 관리자를 삭제하면 세션·인증 코드도 삭제하고(로그인 즉시 종료), 작성한 FAQ는 남김 (FR-032)

  - 요약 메일 하루 1회: `digest_log.digest_date` PK (AVL-009)
  - 학생 이름·학번·기기 ID·IP 컬럼 없음. `fcm_token`만 예외로 두고 발송·만료 후 삭제 (2.6)
- **설계하면서 정한 것 (요구사항에 없던 것)**
  - 관계형 DB로 SQLite를 씀 → 요구사항 2.7에도 반영(E-27)
  - 테이블 이름과 컬럼 타입
  - 질문 통계(`query_log`)를 따로 둠 (FR-025의 일별 질문 수·평균 응답 시간 계산용)
